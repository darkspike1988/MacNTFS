MacNTFS

An experimental, read-only NTFS inspector written in Swift. Not a driver.

Status: early prototype. MacNTFS does not mount NTFS volumes and does not add write support to macOS. Earlier releases (up to v0.2.2) offered writing, formatting and repairing. These functions can produce NTFS data that Windows rejects, and they are now locked. If you used them, back up your data and check the volume in Windows.

What it does today

  • Reads the boot sector and MFT of a disk image or device and lists directories.
  • Reads simple files. Compressed, encrypted and attribute-list files are not handled reliably yet.
  • Experimental forensics helpers. Not validated.

Need to write to NTFS on a Mac?

Other open-source projects build FSKit drivers for this, for example ntfstool, TT NTFS Native and xntfs. This list is based on their own descriptions as of 2026-11-03 and has not been reviewed or tested by this project.
